# 第 1 章 · 导论与总纲

> **本章定位**：动机章 + 全课程地图。不讲具体算法细节，而是**立框架、铺地图、给动机**。
> 阅读方式：不要记公式，要**记骨架**。

---

## 一、什么是最优化？——三要素（全章基石）

PPT 用"人生怎么安排时间""HR 说要优化人员"这类例子，逼出**形式化三要素**：

| 要素 | 人生例子 | 数学记号 |
|---|---|---|
| **决策变量**（我能调什么） | 每天时间怎么分 | x |
| **目标函数**（什么变好） | 收入？健康？快乐？ | f(x) |
| **约束**（底线不能破） | 睡眠不能压到零 | x ∈ X（可行域） |

标准形式：

```
min  f(x)
s.t. x ∈ X
```

> 🔑 **本章最狠的一句话**：首要问题是"**优化谁的目标，又付出了什么代价？**"
> 目标选错，解得再好也是灾难（成本降了但质量降了、短期指标好了但人跑光了）。
> **优化 = 带着镣铐跳舞**：没有约束那叫"求极值"，有约束才是真优化。

## 二、核心骨架：三种"求解范式"

PPT 用一个二次函数 `f(x) = x² − 4x + 5`，从易到难引出**三种完全不同的求解哲学**：

### 范式① 闭式解（Closed-form）——"一步到位"
第 18–20 页。用**配方法**：

```
f(x) = x² − 4x + 5 = (x − 2)² + 1 ≥ 1
→ 最优解 x = 2，最优值 f(2) = 1
```

一般式：`ax² + bx + c = a(x + b/2a)² + (c − b²/4a)`

> **思想**：能用代数直接解出答案，就用它。快、准、可解释。
> 典型：线性回归的 `w = (XᵀX)⁻¹Xᵀy`。

### 范式② 迭代下降——"摸着梯度下山"
现实几乎都**没有闭式解**（高维、非凸）。于是换思路：**不一次求答案，而是迭代逼近**。

核心更新公式：

```
θ_{t+1} = θ_t − η · ∇L
（新参数 = 当前参数 − 学习率 × 当前梯度）
```

> **思想**：梯度指向最陡上升方向，那就往反方向走一步。
> **问题从"解方程"变成"找方向"**。

### 范式③ 黑盒搜索——"连梯度都拿不到时怎么办"
当目标函数**不可导 / 没有解析式**（如调超参数），梯度法失效。三件武器：

- **粒子群 PSO**：模仿鸟群觅食，个体经验 + 群体共享
- **遗传算法 GA**：适者生存 = 选择 / 交叉 / 变异
- **贝叶斯优化 BO**：代理模型 + 采集函数，平衡"深耕已知好区"与"探索未知区"

> **这三者都属于"无梯度优化"，是另一条完全不同的技术路线。**

> 🔑 **一句话记住本章骨架**：
> **能给解析式 → 闭式解；能给梯度 → 迭代下降；什么都没有 → 黑盒搜索。**

## 三、为什么难？——非凸地形的三大"坑"

（第 24–29 页，用越来越复杂的地形图说明）

1. **多重局部最优**：附近最好 ≠ 整体最好；起点不同，终点不同。→ 组合/非凸的核心难点。
2. **鞍点（Saddle Point）**：梯度 ≈ 0，却**不是**最低点，优化卡住、进展缓慢。→ 高维空间的隐形杀手。
3. **尺度不一致（病态）**：不同方向陡缓不同，步长太大来回震荡、太小又爬得慢。→ 催生一堆"自适应"优化器。

---

## 四、优化器的演化逻辑（看动机，别背名字）

（第 30–32 页）所有优化器都在解决上面三个坑：

| 优化器 | 解决什么问题 | 代价 |
|---|---|---|
| **SGD** | 最原始，简单省内存 | 摇摆、步长难调 |
| **Momentum** | 加"惯性"减少左右摆动 | 惯性太大冲过头 |
| **AdaGrad** | 给不同参数自动调步长 | 后期步子太小、变慢 |
| **RMSProp** | 只看近期梯度，缓解 AdaGrad 后期变慢 | — |
| **Adam** | 动量 + 自适应步子，兼顾稳与灵活 | 仍需设基础步长 |
| **AdamW** | 在 Adam 外单独约束权重（防过拟合） | 约束力度要选 |

> 🔑 **一句话**：从"只看当下"→"记住历史方向"→"给每个参数配步长"→"再加权重约束"。
> 是一条**不断打补丁**的进化线。

## 五、背景铺垫：从规则系统到深度学习（第 35–67 页）

本章后半段是"为什么需要优化"的应用铺垫，串联起 AI 全貌：

- **传统软件开发 = 规则驱动**（业务逻辑写死）→ **机器学习 = 从数据找函数**（y = w₀ + w₁x，用成本函数最小化误差）
- **线性回归的凸性使优化变简单**（最小二乘有闭式解 `w = (XᵀX)⁻¹Xᵀy`）
- **深度网络 = 用神经网络做通用近似函数**（神经元 = 激活函数套在 wx+b 上）
- 网络家族：CNN（视觉）、RNN/LSTM/Transformer（语言）、GNN（图结构）、强化学习（序列决策）
- **深度网络的决策变量 = 参数（Parameters）**：模型自动习得的内部变量，百万~数十亿级
- **超参数（Hyperparameters）**：训练前设定、无法直接学习，需经验/实验/AutoML 确定
  - 模型结构类：层数、神经元数、卷积核、激活函数
  - 训练过程类：学习率、Batch Size、Epochs、优化器
  - 正则化类：L1/L2 系数、Dropout、动量系数
- **AutoML / NAS（神经架构搜索）**：让 AI 设计 AI，自动化特征工程/模型选择/超参优化
- **AI for Science**：AI 加速科学发现（新药、数学难题、物理）
- **大模型对齐优化**：RLHF（有益 Beneficial / 诚实 Honest / 无害 Harmless）
  - 四步：①预训练 ②监督微调 SFT ③奖励模型 RM ④强化学习 RL
