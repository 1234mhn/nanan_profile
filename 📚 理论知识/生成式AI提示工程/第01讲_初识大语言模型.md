## 📖 一、大语言模型的基本概念

### ✔️ 我的回答（原始记录）

- **「大」= 数据大**
- **核心任务 = 预测**
- **LLM 与 RNN/LSTM 的区别 = 只听说过 LLM，另外两个没听说过**

### 🔧 纠正与补充

**1. 「大」的真正含义（我的盲区）**

「大」的核心不是数据大，而是 **参数量大**——模型内部参数规模达到 **百亿～千亿级别**（如 7B = 70 亿，70B = 700 亿）。
数据规模、算力规模是**随之变大**的伴随项。

一句话记牢：

> **大 = 参数量大，数据 / 算力跟着一起大。**

**2. 「预测」→ 更精确：预测下一个词（next-token prediction）**

语言模型在做的事：给定前面一串词 → 算出**下一个词的概率分布** → 挑一个输出 → 把这个词接到序列后面 → 继续预测，如此循环。

这个「输出一个、接一个、再继续预测」的过程叫 **自回归生成（autoregressive generation）**。

**3. RNN / LSTM（Transformer 之前的主流序列模型）30 秒补课**

| | RNN / LSTM |
|---|---|
| 处理方式 | **串行**：一词一词按顺序算，前一步结果传给后一步 |
| 优势 | 天然适合序列（句子、语音） |
| 死穴 ① | 句子一长，前面信息会「忘」——**长距离依赖差** |
| 死穴 ② | 只能串行，**无法并行**，训练极慢 |

→ 后来 **Transformer** 用 **自注意力机制（attention）** 解决了这两个问题（第 2 讲核心）。

### 🔁 我的重新梳理（2026-10-13 迭代二 · 原话）

> 大模型 = 大语言模型，全称 Large Language Model。
>
> 先说 Model：是从数据中总结出规律的程序。
> 什么是规律？规律是预测文字的。文字是大语言模型的一个专长。
> 这个「语言」可以指各种语言——自然语言、代码（计算机语言）、数学、科学的语言。
> 那么「大」可以在模型的定义里找到：① 数据海量；② 规律的数量比较大。
> 而数据又是通过向量表示出来的。
> 最后说 AI 和 LLM：AI 是一个大领域，里面有一个机器学习，它是研究广度问题的；
> 深度学习是研究某领域的；最后才是 LLM。
> 所以 LLM 的基础是依靠机器学习和深度学习。

### 🔧 本轮纠正与补充

**① 「语言」的范围——✅ 答得非常漂亮，保留。**

> 「语言」不限于自然语言，还包括**编程语言、数学语言、科学语言**。这正是 LLM 能用代码、能推理的本质原因之一。

**② 层级关系——✅ 正确（AI ⊃ ML ⊃ DL ⊃ LLM），但区分理由要改。**

- AI 是大领域 → 机器学习是 AI 的一个子集 → 深度学习又是机器学习的子集 → LLM 是深度学习里「基于 Transformer 的大模型」这一支。
- ⚠️ 但「机器学习研究广度、深度学习研究某领域」这个说法**不准确**。区别不在「广度 vs 领域」，而在**方法**：
  - 传统机器学习：常需**人工设计特征**（如手工挑特征喂给算法）。
  - 深度学习：用**多层神经网络自动学特征**，端到端从原始数据学。

**③ 「大」的硬指标 = 参数量（关键修正）。**

- 你说的「① 数据海量；② 规律数量大」——**②其实和「参数量大」是一回事的通俗说法**：规律越多，模型里存的参数就越多。所以这样理解**不算错**。
- 但学术/考试口径要答：**「大」最核心的指标是参数量（parameters），达到百亿～千亿级**；数据量大、算力大是伴随项。
- 一句话：**规律数量 ≈ 参数数量**，说法可通，但标准术语是「参数量」。

**④ 数据 → 向量表示——✅ 正确。**

文字在模型内部被转换成 **向量（embedding）** 才能参与计算。这是后面第 2 讲 Transformer 的起点。

**⑤ Model 的精确表述（微调）。**

「从数据中总结出规律的程序」→ 更精确：模型是一个**带参数的函数** y = f(x; θ)，其中参数 θ 由数据训练得到。

### 🔁 追加问答（2026-10-13 13:25）

- ❓ 问：「查缺补漏」具体改什么？
- ✅ 我答：**改参数吧**（正确！改的是模型内部参数，不动数据、不动答案）
- ✅ 我说：**大模型本质上不会思考，它只不过是通过上下文去猜**（核心直觉！）

### 🔧 补充：「不会思考，只是猜」要加一层

- 大方向对：底层机制就是**根据上下文预测概率最高的下一个词**，没有人的那种「意识」。
- 但要注意两层：
  - 「猜」不是乱猜，是**概率最高的那个**（所以能答对大多数问题）。
  - 现在有**推理模型**（思维链，让它「一步步想」再答），但本质**仍然是预测**，只是把「想的过程」也变成了一串要预测的文字。
- 🔑 这一点的深刻含义：**既然它只是根据上下文预测，那么「上下文」就是唯一能操控它的东西** —— 这正好就是「提示工程」存在的理由。

## 📖 二、工作原理（我的讲解 + 纠正）

### 🗣️ 我的讲解（原话 · 2026-10-13）

- 举例：我问 DeepSeek → 它回答。**我给它问题时**，它用监督学习、深度学习的方式 loop 几千万亿次：**学习-考试-评分-调整-再学习**，最后把学完的答案发给我。
- loop 的本质 = 找到一个**又快、又准、又高效**的答案。
- 类比学英语：字母 → 音标 → 单词 → 短语 → 句子 → 文章 → 考试 → 看哪好哪不好 → 查缺补漏 → 再学。
- 机器怎么读文字：把文字都变成**向量**，**向量可以运算**。

### 🔧 纠正：训练 vs 使用（关键！）

🔴 **那个 loop 是「训练阶段」的事（离线、一次性、几个月），不是「我提问的时候」的事。**

**阶段一 · 训练（出厂前）**
- 就是「学习→考试→评分→查缺补漏→再学习」的循环
- 英语类比完全对得上：
  - 学字母/音标/单词/文章 ≈ 喂海量文本、学语言规律（预训练）
  - 考试 ≈ 让模型预测下一个词，和真实答案比对、算差错
  - 看哪好哪不好 ≈ 定位错在哪
  - 查缺补漏 ≈ 调整参数（把模型内部那堆数字改一改）
  - 再学习 ≈ 下一轮循环
- 循环跑完，模型「定型」，参数固定。

**阶段二 · 使用（推理）**
- 🔴 我提问时，它**不再训练、不再 loop 几千万亿次**。
- 只是把我这句话送进「已经学好的」网络，**往前跑一遍**，算出下一个词，再算下一个……一个词一个词往外吐。
- 所以它回答快（秒级），而不是要算几个月。

> **一句话：几千万亿次 loop 发生在它出厂之前；我用它时，它只在「用」，不在「学」。**

✅ 我最后说的「文字→向量、向量能运算」——**正确**，这是机器能计算的根本。
