> 大纲要求：理解大语言模型的基本概念、发展历程与构建流程；了解其能力特点；了解代表性代码库。

## 🧠 我的思考（原话）

### 一、基本概念

**🧠 我的思考（迭代一）**
- 「大」= 数据大
- 核心任务 = 预测
- LLM 与 RNN/LSTM 的区别 = 只听说过 LLM，另外两个没听说过

**🧠 我的思考（迭代二 · 重新梳理）**
> 大模型 = 大语言模型，全称 Large Language Model。
> 先说 Model：是从数据中总结出规律的程序。
> 什么是规律？规律是预测文字的。文字是大语言模型的一个专长。
> 这个「语言」可以指各种语言——自然语言、代码（计算机语言）、数学、科学的语言。
> 那么「大」可以在模型的定义里找到：① 数据海量；② 规律的数量比较大。
> 而数据又是通过向量表示出来的。
> 最后说 AI 和 LLM：AI 是一个大领域，里面有一个机器学习，它是研究广度问题的；深度学习是研究某领域的；最后才是 LLM。所以 LLM 的基础是依靠机器学习和深度学习。

### 二、工作原理

**🧠 我的思考（原话）**
- 举例：我问 DeepSeek → 它回答。**我给它问题时**，它用监督学习、深度学习的方式 loop 几千万亿次：**学习-考试-评分-调整-再学习**，最后把学完的答案发给我。
- loop 的本质 = 找到一个**又快、又准、又高效**的答案。
- 类比学英语：字母 → 音标 → 单词 → 短语 → 句子 → 文章 → 考试 → 看哪好哪不好 → 查缺补漏 → 再学。
- 机器怎么读文字：把文字都变成**向量**，**向量可以运算**。
- 追问「查缺补漏改什么」→ **改参数吧**。
- **大模型本质上不会思考，它只不过是通过上下文去猜。**

## 🔧 对照参考（助手的纠正与补充 · 非我的原话）

### 基本概念

**1. 「大」的真正含义**
「大」的核心不是数据大，而是 **参数量大**（百亿～千亿级，如 70B = 700 亿参数）；数据、算力是伴随项。
> 记法：**规律数量 ≈ 参数数量**，标准术语叫「参数量（parameters）」。

**2. 「预测」→ 更精确：预测下一个词（next-token prediction）**
给定前面一串词 → 算下一个词的概率分布 → 挑一个输出 → 接到序列后面 → 继续预测。这个「接一个、再继续」的过程叫 **自回归生成（autoregressive generation）**。

**3. RNN / LSTM（Transformer 之前的主流序列模型）**
- 串行处理：一词一词按顺序算，前一步结果传给后一步
- 优势：天然适合序列（句子、语音）
- 死穴①：句子一长，前面信息会「忘」——长距离依赖差
- 死穴②：只能串行，**无法并行**，训练极慢
- → **Transformer** 用 **自注意力机制（attention）** 解决了这两个问题（第 2 讲核心）

**4. 层级关系：AI ⊃ 机器学习 ⊃ 深度学习 ⊃ LLM（正确）**
- ⚠️ 但「ML 管广度、DL 管某领域」的说法不准确；区别在**方法**：
  - 传统机器学习：常需**人工设计特征**
  - 深度学习：用**多层神经网络自动学特征**，端到端

**5. 「语言」的范围（✅ 我答对了）**
不限于自然语言，还包括**编程语言、数学语言、科学语言**——这正是 LLM 能用代码、能推理的本质原因之一。

**6. 数据 → 向量（✅ 我答对了）**
文字在模型内部被转成 **向量（embedding）** 才能参与计算，是第 2 讲 Transformer 的起点。

**7. Model 的精确表述**
模型是一个**带参数的函数** y = f(x; θ)，θ 由数据训练得到。

### 工作原理

🔴 **那个 loop 是「训练阶段」的事（离线、一次性、几个月），不是「我提问的时候」的事。**

**阶段一 · 训练（出厂前）** ＝「学习→考试→评分→查缺补漏→再学习」的循环
- 学字母/单词/文章 ≈ 喂海量文本、学语言规律
- 考试 ≈ 让模型预测下一个词，和真实答案比对、算差错
- 看哪好哪不好 ≈ 定位错在哪
- 查缺补漏 ≈ **调整参数**（✅ 我答对了）
- 再学习 ≈ 下一轮循环
- 循环完，模型定型，参数固定。

**阶段二 · 使用（推理）**
- 我提问时，它**不再训练、不再 loop**；只是把我这句话送进「已经学好的」网络**往前跑一遍**，算出下一个词，再算下一个……一个词一个词往外吐。
- 所以秒级回答，而不是现算几个月。

> 一句话：**几千万亿次 loop 在它出厂之前；我用它时，它只在「用」，不在「学」。**

**「不会思考，只是猜」的补充**
- 对：底层就是**根据上下文预测概率最高的下一个词**，没有人的「意识」。
- 「猜」不是乱猜，是**概率最高的那个**（所以大多答得对）。
- 有**推理模型**（思维链，让它「一步步想」再答），但本质**仍是预测**。
- 🔑 深层含义：**既然它只是根据上下文预测，那「上下文」就是唯一能操控它的东西** —— 这正是「提示工程」存在的理由。

## 🔗 知识联想（可以牵出哪些知识点）

- **向量运算 / embedding** → 线代基础（向量、矩阵、余弦相似度）；后面 Transformer 的起点
- **监督学习** → 我学过：分类与回归、逻辑回归、决策树…（在 `📚 理论知识/监督学习/`）；训练里的「考试→评分→调参」本质就是监督学习里的「损失 → 反向传播 → 更新参数」
- **深度学习 / 神经网络** → 多层网络自动学特征 / 反向传播（自动求导）
- **自回归生成 / next-token prediction** → 与 NLP 语言建模（LM）一脉相承
- **注意力机制（attention）** → 第 2 讲 Transformer 核心
- **"幻觉"（hallucination）** → 正是因为"只是预测、不是查证"，才会编造不存在的东西 → 牵到课程后续「负责任 AI / 事实核查」
- **"上下文就是唯一能操控它的东西"** → 直接连到本课主线：**提示工程 / 提示设计 / 上下文学习（ICL）**
- **训练 vs 推理** → 牵到「微调（fine-tuning）」：微调是"再训练一下"，推理是"用"
- **参数规模** → 牵到「参数高效微调（LoRA）」：不重训整个大模型也能改行为（第 3 讲）
- **参数量 → 向量维度 → 算力/显存** → 牵到「本地部署」（大纲第 8 讲）
