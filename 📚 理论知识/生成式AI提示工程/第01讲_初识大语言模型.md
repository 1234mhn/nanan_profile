### 🔧 纠正与补充

**1. 「大」的真正含义（我的盲区）**

「大」的核心不是数据大，而是 **参数量大**——模型内部参数规模达到 **百亿～千亿级别**（如 7B = 70 亿，70B = 700 亿）。
数据规模、算力规模是**随之变大**的伴随项。

一句话记牢：

> **大 = 参数量大，数据 / 算力跟着一起大。**

**2. 「预测」→ 更精确：预测下一个词（next-token prediction）**

语言模型在做的事：给定前面一串词 → 算出**下一个词的概率分布** → 挑一个输出 → 把这个词接到序列后面 → 继续预测，如此循环。

这个「输出一个、接一个、再继续预测」的过程叫 **自回归生成（autoregressive generation）**。

**3. RNN / LSTM（Transformer 之前的主流序列模型）30 秒补课**

| | RNN / LSTM |
|---|---|
| 处理方式 | **串行**：一词一词按顺序算，前一步结果传给后一步 |
| 优势 | 天然适合序列（句子、语音） |
| 死穴 ① | 句子一长，前面信息会「忘」——**长距离依赖差** |
| 死穴 ② | 只能串行，**无法并行**，训练极慢 |

→ 后来 **Transformer** 用 **自注意力机制（attention）** 解决了这两个问题（第 2 讲核心）。
